## 📖 About

Jacobabad is a city and district capital in northern Sindh, founded in 1847 by Brigadier-General John Jacob. This site gives the city a modern web presence — one place to learn its history, discover places worth visiting, watch a video tour, and stay connected with local news.

> 🔗 **Live:** [jacobabad.vercel.app](https://jacobabad.vercel.app/)

## ✨ Features

- 🔍 **Smart hero search** — jumps straight to any location on Google Maps
- 🏛️ **History timeline** — the founding of Jacobabad and its growth into a district capital
- 📍 **8 Places to Visit** — Railway Station (JCD), Victoria Tower, Green Dome Mosque, Grand Domed Shrine, Blue-Tiled Shrine, village life, Thull & Garhi Khairo tehsils, each with a full history panel
- 🎬 **Video tour** — embedded city tour video with native playback controls
- 🖼️ **Photo gallery** — categorized, lightbox-enabled gallery
- 🗺️ **Interactive map** — embedded Google Map with quick-search
- 📰 **Local newspapers** — links to Kawish, Sindh Express, Ibrat, Dawn, and The News International
- ✉️ **Working contact form** — real email delivery via FormSubmit, no backend required
- 🌗 **Light / dark theme toggle**
- 📱 **Fully responsive** — mobile-first, tested across phone, tablet, and desktop
- 🔎 **SEO-ready** — structured data, Open Graph/Twitter tags, sitemap & robots.txt

## 🛠️ Tech Stack

A dependency-free static site — no framework, no build step, no bundler.

| Layer | Technology |
|---|---|
| Markup | HTML5 (semantic) |
| Styling | CSS3 — custom properties, Grid & Flexbox |
| Behavior | Vanilla JavaScript (ES6+) |
| Forms | [FormSubmit](https://formsubmit.co/) — serverless email delivery |
| Hosting | [Vercel](https://vercel.com/) |

## 🚀 Getting Started

No build tools or dependencies required.

```bash
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>
python3 -m http.server 8000   # then visit http://localhost:8000
```

Or just open `index.html` directly in a browser.

## 🌐 Deployment

Static site — hostable anywhere. **Currently deployed on [Vercel](https://vercel.com/)** at [jacobabad.vercel.app](https://jacobabad.vercel.app/), connected directly to this repository for automatic deploys on every push to `main`.

## ✉️ Contact Form

Submits to [FormSubmit.co](https://formsubmit.co/). The first submission triggers a one-time confirmation email; after confirming, every message delivers automatically. To change the destination, edit the form's `action` in `index.html`.

## 🔎 SEO

Includes structured data (JSON-LD), Open Graph/Twitter Card tags, `robots.txt`, and `sitemap.xml`. Submitted to [Google Search Console](https://search.google.com/search-console) for indexing under the "Jacobabad" and "JCD" search terms.
